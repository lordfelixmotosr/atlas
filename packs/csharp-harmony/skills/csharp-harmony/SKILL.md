# C# and framework references
Read exact recipes under `../../references/cookbook/` relative to this skill folder. Inspect installed framework versions and method signatures before patching. Prefer ordinary XML, comps and framework hooks when they satisfy the requested behavior. Compile against installed game assemblies; a successful compile does not prove runtime behavior.

For RimWorld 1.7, first read `../../references/RIMWORLD-1.7.md`. Use the selected installation and its current index; older recipes may describe Unity 1.6. Do not automatically add 1.7 to an existing mod’s supportedVersions.
